# status-dos-Servidores
Script Php que gera uma tela com o retorno dos servidores e informa se estão ativos ou não.

Esse Script eu desenvolvi para solucionar um problema que tinhamos no nosso fluxo de trabalho, que era a duvida de saber, se o servidor havia caído somente para o cliente, para nossa internet por algum bloqueio de DNS ou se o servidor realmente tinha algum problema de entrega da aplicação.

O script têm a principal meta informar os servidores e testar se estão onlines com algumas pequenas informações sobre os serviços.

Fiquem livres para baixar e testar com seus sites dos seus clientes ou suas aplicações webs. :)
